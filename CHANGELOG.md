## [0.1.0] - 2026-08-04

### Added

- Framework-neutral PHP collector, MySQL storage, goals, reports, heatmaps and replay reads.
- TypeScript tracker with autocapture, attribution, ecommerce, diagnostics, heatmaps and rrweb recording.
- Laravel 13 integration with PostgreSQL partitions, queued ingestion, rollups, object storage and an authenticated dashboard.
- Plain PHP integration examples and publishing documentation.
